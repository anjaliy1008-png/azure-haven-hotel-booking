# Azure Haven Hotel Booking

A beginner-friendly hotel booking website built with HTML, CSS, vanilla JavaScript, and `localStorage`.

## Run it

Open `index.html` in a browser. No installation or server is required.

## Demo administrator

- Email: `admin@azure.com`
- Password: `admin123`

## Main features

- Registration, login, logout, and profile editing
- Room search, filters, sorting, and details pages
- Date-based booking total calculation and overlap prevention
- Booking history and cancellation
- Admin dashboard to manage rooms and booking status

All information is stored in the browser's localStorage. To reset the demo, clear the site's browser storage.
